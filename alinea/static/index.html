    Creare il programma .PRG in PC-DMIS
    
    
    Il .PRG è un formato chiuso di Hexagon: lo può scrivere solo PC-DMIS. Hai scaricato lo script
      , che lo crea dentro PC-DMIS in pochi secondi:
    
    
      
      
    1. In PC-DMIS apri l'editor degli script BASIC (menu Strumenti › Editor script BASIC,
        in inglese Tools › Basic Script Editor).
      2. 
      
    2. File › Apri e scegli il file scaricato, poi Esegui (F5).
      3. 
      
    3. Indica dove salvare il .PRG e se sei online o offline: lo script crea feature, allineamenti e
        dimensioni, salva il programma e mostra un rapporto.
      4. 
    
    
    
    Se qualche comando non riesce, il rapporto (e il file .alinea.log accanto al .PRG)
      dice quale: mandamelo e lo sistemo. Prima del DCC verifica sempre il programma con la simulazione.
